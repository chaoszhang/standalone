# wga — 基于指纹的多倍体感知全基因组比对器

单文件 C++20 实现，无外部依赖。三件事：**自比对找重复**、**全基因组比对**、**把 query 回贴到 ref 骨架生成 MSA**。

设计要点：

- **14-mer seed + `%7` 抽样**：28-bit 键空间（`4^14/7 ≈ 3840 万`槽位），1 Gbp 基因组的桶均只有 3.7，避免 12-mer 的键空间饱和。
- **192-bit 双层指纹**（每个 seed 一份）：近场左右各 16 bp 的 2-bit 相位码（64 bit）+ 远场左右各 128 bp 的 3-mer 存在位图（2×64 bit）。远近两种判据的失效模式互补——近场抗替换、远场抗 indel。
- **漂移容差 DP 链化**：允许 `|Δq − Δr| ≤ 0.125·Δr + 40`，2% indel 下不会碎块。
- **短读走"逐读判真"**：指纹只负责把每读 ~290 个候选压到 top-8，再用全读带状全局比对取 identity 最高者定案。
- **分块流式**：查询按 `--chunk` 分块，内存与数据量解耦（4 Gbp × 5X 峰值 28 GiB）。

---

## 编译

```bash
g++ -O2 -std=c++20 -pthread -o wga3   wga3.cpp
g++ -O2 -std=c++20         -o maskfa  maskfa.cpp
```

需要 GCC 13+（用到 `std::atomic<T[]>`）。`./wga3 --selftest` 会用暴力实现逐位对拍 seed 扫描与指纹打包，输出 `PASS` 才算可信任。

## ⚠️ 比对和回贴前，请先自比对去重

**这是最重要的使用约定，不是可选项。**

重复序列（转座子、rRNA、卫星、segmental duplication）会造成两个后果：

1. **候选爆炸**。一个落在重复区的 read / 锚点，会在几十上百个几乎等价的位点上拿到同样高的指纹分。`--topk 8` 的 8 个名额被同一族重复位点占满，真正的唯一匹配位置反而挤不进来。
2. **覆盖虚高**。重复区之间互相"比对成功"，把不该算的 bp 算进覆盖。实测鸡 × 鸵鸟时，跨物种比对的链内 gap 从 5 kb 放宽到 20 kb，覆盖会从 21.5% 虚增到 **59.5%** —— 多出来的 38 个百分点几乎全是重复区串起来的假块。

自比对去重能同时压掉这两件事。实测重复占比：**鸡 6.31%、鸵鸟 3.52%**；4 Gbp 随机序列（无重复）自比对仍报出 5100 万个小块，屏蔽后跨物种覆盖不变，说明该步骤对干净数据也无害。

所以标准流程是 **自比对 → 屏蔽 → 再比对 / 回贴**。

## 用法一：自比对（找重复）

```bash
# 1) 基因组自己比自己；-S 排除主对角线（否则每个位置的最佳匹配永远是它自己）
./wga3 -S -f 300 -t 32 genome.fa genome.fa > self.paf 2> self.log

# 2) 按 PAF 区间把重复段屏蔽成 N
./maskfa genome.fa genome.masked.fa self.paf --min-span 300 --min-id 0.65
```

`maskfa` 的参数：

| 参数 | 含义 |
|---|---|
| `--min-span INT` | 只屏蔽长度 ≥ 该值的块（默认 300） |
| `--min-id F` | 只屏蔽 identity ≥ 该值的块（默认 0，即不筛） |
| `--soft` | 软屏蔽（转小写）而不是硬屏蔽成 N |
| `--drop-diag N` | 丢弃 `|ref−qry| < N` 的同位点块（用于"块 vs 全基因组"这种坐标系不一致的场合） |

**注意**：自比对必须整体跑，不要分块。块 vs 全基因组时 `-S` 的坐标判据跨坐标系失效，而且"每个 ref 位置留最佳"会让完美自匹配挤掉所有重复对（实测 195 Mb 分块只出 21 块，全是对角线）。

建议 `-f 300`（比常规比对高一些），因为重复块本身的 identity 很高，低阈值会捞进大量低复杂度碎片。

## 用法二：比对

### 长序列（contig / scaffold / 染色体级）

```bash
./wga3 -f 250 -g 5000 -t 32 ref.masked.fa qry.masked.fa > out.paf 2> out.log
```

- `-g` 是链内最大 gap。**跨物种比对务必用 5000 或更小**；20 kb 会把不可比对段也串进块，覆盖虚高（见上）。
- 输出是标准 12 列 PAF，附加 `id:f=` / `dv:f=`。

实测：鸡（1.05 Gb）× 鸵鸟（1.23 Gb），30% 分化，`-g 5000` →

| 指标 | 值 |
|---|---|
| 块数 | 32,182 |
| 去重覆盖 | **21.47%（224.8 Mb）** |
| 跨度加权 identity | 0.804（p25 0.750 / p50 0.791 / p75 0.832） |
| 耗时 / 峰值内存 | 5 min / 35.5 GB |

### 短读（150 bp 级别）

```bash
./wga3 --reads 150 -f 450 --topk 8 --chunk 8000000 -t 16 \
       ref.masked.fa reads.fa > out.paf 2> out.log
```

- **必须加 `--reads LEN`**。它让查询按 `padL + read + padR` 紧凑打包（无 N 间隔），记录号 O(1) 反算；不加的话 1.33 亿条读会浪费 133 GB 填充。
- `--topk` 是每读参与全读比对的候选数，`--min-id` 是定案门限（默认 0.70）。
- `--chunk` 是每块的读条数，直接决定内存：`内存 ≈ 17 + 2 + 块数×246×2 B`（GB）。4 Gbp 参考 + 800 万读/块 ≈ 28 GiB。
- 输入必须是 **FASTA**（reads 也要转成 FASTA，不接受 FASTQ）。

实测（4 Gbp 参考，1.33 亿条 150 bp 读 = 5X，20% 替换 + 2% indel）：

| 指标 | 值 |
|---|---|
| 参考去重覆盖 | **80.78%**（3,231,265,944 bp） |
| 映射读 | 37,854,857（28.4%） |
| identity | mean 0.80 |
| 耗时 / 峰值内存 | **16:52 / 28.23 GiB**（16 线程，绑单 socket） |

同一份数据 128 线程整条查询（不分块）是 5:56 / 105.9 GiB —— **16 线程反而更划算**（208 核·分钟 vs 768 核·分钟），因为 128 线程已经把内存带宽跑满，多出来的核都在等带宽。

## 用法三：回贴（生成 MSA）

把 query 的碱基按 ref 骨架贴回去，输出与 ref **同记录数、同列数**的 FASTA，可直接 `cat` 成 MSA。query 相对 ref 的 **insertion 会被丢弃**（这是骨架式 MSA 的固有代价）。

```bash
./wga3 --reads 150 -f 450 --topk 8 --chunk 8000000 --msa qry.on.ref.fa \
       ref.masked.fa reads.fa > out.paf 2> out.log

cat ref.masked.fa qry.on.ref.fa > aln.fa     # 两行即一条 MSA
```

> ⚠️ 输出的记录名沿用 ref。直接 `cat` 会得到两条**同名**记录，多数工具（包括 `samtools faidx`、
> 多数 MSA 解析器）只认第一条。拼之前先加前缀：
>
> ```bash
> sed 's/^>/>ref_/' ref.masked.fa > a.fa
> sed 's/^/>qry_/' qry.on.ref.fa > b.fa
> cat a.fa b.fa > aln.fa
> ```

画布与判定规则：

- 每列 1 字节 = A/C/G/T 各 2-bit 计数（饱和到 3），4 Gbp 占 4 GB。
- **多数票**；`仅 1 票` / `平票` / `次大 ≥ 2` 一律输出 `N`。
- `--gapmask INT`（默认 2）：gap 两侧各 2 列不投票。indel 的 gap 位置本身有 ±1~2 列歧义（重复区尤甚），不排除的话同一批 read 会把相邻碱基对到错误的列。

**为什么是"判不了就 N"而不是"猜一个"**：单条 read 在 5X 下平均只有 1.4 条有效覆盖，任何"先到者占优"的写法都会把测序错误原样输出。要求 ≥2 票、平票即 N，可以把"造出一个该位点从未出现过的碱基"的概率压到 0.05%。

实测（2 Mbp 真值集，判据 = 输出碱基必须是该位点真实出现过的等位基因）：

| 数据 | 错误率 | N（判不了） | 真杂合检出 |
|---|---|---|---|
| 5X，20% + 2% indel | **0.0453%** | 8.01% | — |
| 5X，20% + 0% indel | **0.0058%** | 0.00% | — |
| 6X 二倍体（1% 杂合） | **0.0001%** | 0.034% | **98.72%** |

二倍体：杂合位点输出 `N`（也接受输出任一 allele），纯合位点输出该碱基。**5X 折合每 haplotype 2.5X，"两个 haplotype 都重建"的物理上限只有 31.9%**，要各 80% 需要 ~16X。

## 常用参数

| 参数 | 默认 | 说明 |
|---|---|---|
| `-f INT` | 250 | 最小分数（100·z）。长序列 250；短读 450；自比对 300 |
| `-t INT` | min(16,cores) | 线程数 |
| `-g INT` | 20000 | 链内最大 gap。**跨物种用 5000** |
| `-c INT` | 200 | seed 桶占用上限（重复序列保险） |
| `--reads INT` | 0 | 定长读模式（短读必用） |
| `--topk INT` | 5 | 每读参与全读比对的候选数（实盘用 8） |
| `--min-id F` | 0.70 | 读定案的最低 identity |
| `--chunk INT` | 8000000 | 每块读条数（决定内存） |
| `--msa FILE` | — | 输出回贴结果 |
| `--gapmask INT` | 2 | 回贴时 gap 两侧不投票的列数 |
| `-S` | — | 自比对模式（排除同位点） |
| `--selftest` | — | 与暴力实现对拍 |

启动时会打印 `[calib]` 行，给出**实测零假设分布**和"当前阈值落在第几分位"，跨基因组规模换参数时以此为准，不要靠猜。

## 辅助工具

| 文件 | 用途 |
|---|---|
| `maskfa.cpp` | 按 PAF 屏蔽区间（自比对去重的第二步） |
| `mkrnd.cpp` | 生成随机参考序列（`mkrnd 4000000000 <seed>`） |
| `mkreads.cpp` | 从参考生成定长读，**读名里带真实起点**（`mkreads ref.fa out.fa <readLen> <sub> <indel> <seed> [strands]`，`strands=1` 时正反链各半） |
| `mkdiploid.py` | 造两个 haplotype（含指定杂合率），用于二倍体验证 |
| `check_reads.py` | 用 `mkreads` 的真值核对映射位置正确率 |
| `check_msa_err.py` | 核对回贴结果的"第三方碱基"错误率 |
| `check_het.py` | 核对杂合检出率与假杂合率 |
| `uni.py` | 按 ref 区间并集算去重覆盖（不是简单累加块长） |
| `tpack.cpp` | ref 4-bit 打包的往返自检 |

`mkreads` 生成的读名形如 `t12345_f`（真实起点 12345、正链），配合 `check_reads.py` 可以直接量位置精度，不必靠 identity 间接判断。

## 已知限制

1. **24-bit → 28-bit 键空间仍会随规模饱和**。4 Gbp 参考的 5.71 亿条 seed 已把桶均推到 14.9；再大就得加长 seed（16-mer 把桶占用降两个数量级）或调整抽样率。
2. **短读召回是 seed 层的硬上限**。14-mer 在 20% 分化 + 2% indel 下存活率约 3.3%，150 bp 读只有约 32% 能拿到 seed。5X 的理论上限 85%，实测 80.8% 已贴近；**2X 做不到 80%（上限 54%）**。
3. **回贴丢弃 query insertion**，会抹掉 haplotype 间的 indel 差异。
4. **单行 + N 是 IUPAC consensus**，不是两条 haplotype 各一行；要分 haplotype 需要 phasing。
5. **输入只接受 FASTA**（gzip 会自动解压）。
6. identity 来自全读带状全局比对（不在比对两端自由），因此不含"局部最佳段"的虚高；但它衡量的是"整条读"而非"块"，与块级 identity 不完全等价。
